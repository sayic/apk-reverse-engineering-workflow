# Using Skills

Start the AI at the repository root, read AGENTS.md, and then read the relevant SKILL.md below. These are shared repository entry points, not necessarily skills installed in a member's personal skill list. You can also explicitly provide a file path in your request.

- [Extract resources from an APK](../apkbreak_skills/extract/SKILL.md)
- [Convert unpacked art resources and import into Unity](../apkbreak_skills/art/SKILL.md)
- [Recover unpacked code and organize code projects](../apkbreak_skills/code/SKILL.md)
- [Restore unpacked data tables and export to Excel](../apkbreak_skills/config/SKILL.md)
- [Download and organize remote resources](../apkbreak_skills/download/SKILL.md)
- [Map data tables and modify target tables](../apkbreak_skills/mapping/SKILL.md)
- [Repair effects, materials, and textures](../apkbreak_skills/repair/SKILL.md)
- [Check file and directory conventions](../apkbreak_skills/check/SKILL.md)
- [Create and update context records](../apkbreak_skills/context/SKILL.md)
- [Query and analyze parsed resources](../apkbreak_skills/query/SKILL.md)
- [Parse resource containers](../apkbreak_skills/container/SKILL.md)
- [Import parsed art resources into another project](../apkbreak_skills/import/SKILL.md)

Example: read apkbreak/apkbreak_skills/extract/SKILL.md, extract code and config from the specified APK, and record results according to the rules. Provide the package and confirm its version before execution.

For continuation, provide the original task directory. Calling a subskill does not create a separate task record.
