# Glossary

| Name | Meaning |
| --- | --- |
| apks | Original installation packages and accompanying inputs |
| unpacked | Extracted, downloaded, decrypted, or reassembled materials awaiting conversion, organized by task |
| outputs | Organized resources or projects; directory names do not indicate full acceptance |
| art | Models, textures, materials, Shaders, Prefabs, animations, effects, and accompanying audio/video |
| code | Assemblies, scripts, and recovered code, with recovery level stated |
| config | Data tables and business configuration |
| info | Basic information for a single APK |
| context | Task facts, status, artifact entry points, changes, and continuation instructions |
| rules | Shared conventions for all tasks |
| skill | Applicability, steps, boundaries, and completion criteria for a task type |
| tools | Scripts, programs, and plugins that perform processing |
| Container | A format that holds multiple files or objects, such as AssetBundle |
| Part | A portion split according to a defined scheme; assembly requires ordering, offsets, or other evidence |
