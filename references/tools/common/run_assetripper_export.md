# AssetRipper HTTP Export

Drive a local AssetRipper already started by the user, recording settings, loading, and export stages separately.

- Documented interface version: 1.0; expected runtime: Python 3.10+. The implementation is not bundled.
- Inputs: local service URL, input directory, new candidate output directory, applicable tool version, and settings JSON for that version.
- Outputs: JSON stage report and the candidate project generated by AssetRipper.
- Exit codes: 0 means completion within this tool's scope; 2 means failed checks, partial completion, or invalid parameters; other nonzero codes indicate exceptions. Retain existing results after exceptions without treating them as complete success.
- Before use: replace example paths with the actual task paths. Write outputs to candidate directories and use new report paths for the current execution. Run commands from the user-selected task workspace root. The script location below is a placeholder for a separately obtained, compatible implementation.

```powershell
python "<configured-tool-directory>/common/run_assetripper_export.py" --server "<local_service_address>" --input "unpacked/task_directory/assetripper_input" --output "unpacked/task_directory/new_export" --settings "unpacked/task_directory/assetripper_settings.json" --tool-version "installed-version" --report "context/task_directory/logs/assetripper_run1.json"
```

Requires a separately installed, running AssetRipper service. Prepare settings for the actual version; they may include confirmed DefaultVersion, TargetVersion, and ShaderExportMode values. No Unity version, Dummy Shader mode, or old project path is built in. Interfaces follow the older tool's /Settings/Update, /LoadFolder, and /Export/UnityProject; confirm compatibility for different versions.

HTTP failures stop subsequent calls; loading state is not treated as export state. Successful requests with nonempty outputs are marked generated_unverified, not accepted. A timeout may mean the service is still working; inspect the process before continuing. Require new output directories to prevent the external exporter from overwriting older projects.

See the [tool overview](../README.md) for versions and validation scope. Actual tasks record input hashes, full parameters, logs, exit codes, and artifact locations. This tool does not write the main task's summary/status.
